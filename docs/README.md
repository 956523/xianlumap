## 值得单独记住的两条实测教训

写在这里，因为它们是**只有跑起来才会发现**的，看代码看不出来：

### 一、显示层不得放大数据缺陷

S0 实现时，纯按像素去重导致 z=5.5 时显示层站间空档 **554km**，
而全量真实数据只有 **199.9km** —— **显示层凭空造了 354km 的"假无人区"**。

根因：覆盖率锚点被一起送进像素去重，40px 阈值在 z=5.5 时约等于 120km 实地距离，
把 60km 一个的锚点自己吃掉了。

修法：锚点**直接入选，不参与像素去重**。修好后显示层与真实数据 **1:1 还原**。

### 二、同一个加油站在图上出现了两个位置

页面里长期同时挂着两套站点图层：

- 旧的 `fuelMarkers` / `evMarkers` —— 早期手打的 `FUELS` / `EVS` 各 12–13 个示例站
- 新的 `dimFuelM` / `dimEvM` —— 真实 `STATION_DATA`（282 充电 + 193 加油）

两套叠着画 169+ 个点，而且**坐标不一致** —— 等于数据自己打自己脸。已删除旧图层。
